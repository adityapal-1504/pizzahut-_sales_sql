# Pizza Sales SQL Project

## Project Overview
This project analyzes pizza sales data using SQL.

The objective of this project is to:
- Analyze sales performance
- Identify top-selling pizzas
- Understand customer ordering patterns
- Generate business insights using SQL queries

---

## Tools Used
- MySQL
- SQL
- GitHub

---

## Dataset
The dataset contains:
- Orders data
- Pizza details
- Pizza categories
- Pricing information

---

## SQL Concepts Used
- SELECT
- JOIN
- GROUP BY
- Aggregate Functions
- Window Functions
- CTEs
- Revenue Analysis

---

## Project Levels

### Basic Analysis
- Total Orders
- Total Revenue
- Most Ordered Pizza

### Intermediate Analysis
- Hourly Sales
- Category-wise Sales
- Revenue Analysis

### Advanced Analysis
- Cumulative Revenue
- Ranking Functions
- Revenue Contribution

---

## Key Insights
- Large pizzas generated the highest revenue
- Peak ordering hours were during evenings
- Classic category pizzas were most popular
